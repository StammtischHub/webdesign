# Showcase Website

Diese Websites entstanden im Rahmen des Moduls *Webdesign und Standards II* an der Berufsakademie Rhein-Main im Rahmen unseres Informatik Studiums.

Das Ziel des Projekts war die Entwicklung einer gemeinsamen Website, die mehrere individuelle Themenwebseiten unter einem einheitlichen Dach zusammenführt. Jeder Projektteilnehmer entwickelte dann eine eigene Website mit individuellem Thema, Design und Inhalt.

## Technischer Ansatz der Gruppenseite

Die besondere Herausforderung dieses Projekts bestand darin, moderne Designvorstellungen mit bewusst eingeschränkten Technologien umzusetzen.

Die gesamte Gruppenseite wurde ausschließlich mit XHTML 1.0 Strict und CSS 2.1 entwickelt. Auf moderne Werkzeuge und Versionen wurde vollständig verzichtet.

Trotz dieser Einschränkungen sollte ein zeitgemäßes Erscheinungsbild mit einer intuitiven Benutzerführung und einer ansprechenden visuellen Gestaltung entstehen.

## Technischer Ansatz der Individual Seiten

Hier waren wir sehr frei. Es sollten lediglich Pflichtelemente wie Video, Audio, Canvas und SVG beinhalten. Hier lag der Fokus auf Kreativität und semantische Korrektheit, sowie auf ein ansprechendes visuelles Design.

## Repository-Struktur

Dieses Repository enthält damit sowohl die zentrale Gruppenseite als Absprungpunkt zu den individuellen Projektseiten aller beteiligten Studierenden.

Alle Teilprojekte wurden im Rahmen derselben Lehrveranstaltung entwickelt und bilden gemeinsam die finale Projektabgabe.

## Lernziele

Dieses Projekt diente insbesondere der Vertiefung folgender Themen:

- Semantisches Markup
- Webstandards und Validität
- Design-to-Code-Umsetzung
- Strukturierung von Webseiten
- UI- und UX-Grundlagen
- Historische Entwicklung von Webtechnologien
- Freiwilliges responsives Webdesign
